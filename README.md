# Project UpNorth

Simple static marketing site for **UpNorth** — flat-monthly-plan websites for small businesses.

No build step required.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Files

- `index.html` — page markup
- `style.css` — styling
- `script.js` — nav toggle + footer year
